    About Mini PWA Engine
    
  
    A visual builder for small progressive web apps, in one dependency-free page. Lay out the screen, connect data, describe what buttons do; the engine writes the app's own code (no framework to install), a service worker and a manifest. When the app needs them it also writes web, API and application servers, a database schema, setup notes, and a terminal version of the same app.
    
  
    Projects are kept in this browser. Use Save to keep a copy as a file.
